🇸🇦 اختر الطريقة الأنسب لك: لا يوجد خادم سعودي مجاني دائم بدون شروط. أضفنا بدائل أسهل من Oracle: جهاز سعودي عبر Tailscale، أو تجربة Google Cloud، أو أي VPS سعودي.
💡 الأسهل والمجاني: إذا عندك جهاز داخل السعودية (كمبيوتر، Raspberry Pi، أو جهاز صديق/قريب بإذنه)، حوّله إلى مخرج VPN عبر Tailscale. الخطة الشخصية مجانية، ولا تحتاج بطاقة بنكية ولا فتح منافذ غالبًا.

🟢الخطوات بالتفصيل
  1. أنشئ حسابًا في Tailscale واختر الخطة الشخصية المجانية.
  2. على جهاز Linux داخل السعودية، شغّل الأمر المجاور. سيثبّت Tailscale ويعلن الجهاز كـ Exit Node.
  3. افتح Machines في لوحة Tailscale، اختر الجهاز، ثم Edit route settings ← Use as exit node.
  4. على جوالك/لابتوبك ثبّت Tailscale، سجل بنفس الحساب، ثم من Exit Node اختر الجهاز السعودي.
  5. ارجع لتبويب فحص الاتصال وتأكد أن IP أصبح سعوديًا 🇸
⚙️أمر التجهيز على الجهاز السعودي

شغّله على Ubuntu / Debian / Raspberry Pi OS داخل السعودية:

curl -fsSL ... | sudo bash
⬇ تحميل السكربت تحميل Tailscale للأجهزة
✅ مناسب إذا كان لديك جهاز دائم التشغيل داخل السعودية. لا تشارك جهازًا غير مخوّل، واستخدمه وفق شروط الخدمة.
☁️ تجربة سحابية: Google Cloud يعطي رصيدًا تجريبيًا 300$ لمدة 90 يومًا، ويوجد منطقة الدمام me-central2. يتطلب بطاقة تحقق، وليس مجانيًا دائمًا. احذف الخادم بعد التجربة لتجنب الرسوم.

ثبّت اللوحة

ادخل SSH وشغّل أمر WireGuard

☁️الخطوات بالتفصيل
  1. سجّل في Google Cloud Free Trial وأكمل تحقق البطاقة.
  2. أنشئ مشروعًا أو استخدم مشروعًا قائمًا، ثم افتح Cloud Shell.
  3. شغّل الأمر المجاور. سينشئ خادمًا في الدمام ويفتح UDP 51820 وTCP 3000.
  4. ادخل للخادم عبر SSH كما يطبع السكربت، ثم شغّل أمر تثبيت WireGuard.
  5. افتح اللوحة على http://SERVER_IP:3000 وأضف أجهزتك.
⚙️أمر Cloud Shell

شغّله داخل Google Cloud Shell بعد تسجيل الدخول:

curl -fsSL ... | bash
⬇ تحميل السكربت فتح Google Cloud
⚠️ لتجنب الرسوم بعد التجربة: احذف الـ VM وقواعد الجدار الناري كما يطبع السكربت في النهاية.
🖥️ تحكم كامل: استخدم أي خادم سعودي (Oracle، مزود محلي، أو غيره) وثبّت WireGuard + لوحتنا بأمر واحد.
☁️1) جهّز خادمًا سعوديًا
  1. اختر مزودًا بمنطقة سعودية: جدة / الرياض / الدمام.
  2. أنشئ خادم Ubuntu 22.04 / 24.04 أو Debian 11/12.
  3. افتح UDP 51820 وTCP 3000 في الجدار الناري السحابي.
  4. ادخل عبر SSH، ثم شغّل أمر التثبيت المجاور.
⚙️2) شغّل أمر التثبيت

الصق هذا الأمر في طرفية الخادم السعودي (SSH):

curl -fsSL ... | sudo bash

أو نزّل السكربت وارفعه للخادم يدويًا:

⬇ تحميل سكربت التثبيت
curl -fsSL https://raw.githubusercontent.com/mohammedsabryalfiqi/Saudia-vpn/main/scripts/install-wireguard.sh | sudo bash
✅قائمة تحقق سريعة
  • الخادم أو الجهاز المخرج موجود فعليًا داخل السعودية.
  • لـ WireGuard: منفذ UDP 51820 مفتوح في الجدار الناري السحابي.
  • لـ Tailscale: تم تفعيل Use as exit node من لوحة Tailscale.
  • لـ Google Cloud: احذف الموارد بعد التجربة لتجنب الرسوم.
  • بعد الاتصال، استخدم تبويب فحص الاتصال للتأكد من IP السعودي.
🧠ملاحظات مهمة
  • بعض منصات البث تحظر عناوين مراكز البيانات — IP السكني عبر Tailscale قد يكون أفضل.
  • لا تستخدم جهازًا غير مخوّل، ولا تشارك اتصالًا يخالف شروط الخدمة.
  • غيّر كلمة مرور اللوحة فورًا، وفعّل HTTPS لاحقًا إن أردت.
  • النظام مفتوح المصدر بالكامل — راجع الكود على GitHub قبل التثبيت.

    هل تتصفح الآن من السعودية؟

    🧪اختبارات إضافية
    • اختبار تسريب DNS: dnsleaktest.com
    • فحص شامل للخصوصية: whoer.net
    • تأكد أن خانة AllowedIPs في التطبيق تساوي 0.0.0.0/0, ::/0
    • أوقف أي VPN أو بروكسي آخر قبل الفحص لتجنب التعارض.
    🛠️لا يظهر IP سعودي؟
    • تأكد أن النفق مفعّل (مفتاح التشغيل أخضر في تطبيق WireGuard).
    • افتح منفذ UDP 51820 في الجدار الناري السحابي — أشهر سبب للمشاكل.
    • تأكد أن الخادم نفسه في منطقة سعودية وليس منطقة أخرى.
    • أعد استيراد ملف الإعداد بعد أي تغيير في الإعدادات.
    • أعد تشغيل الخادم أو خدمة WireGuard: sudo systemctl restart wg-quick@wg0
