☁️1) أنشئ خادمًا سعوديًا مجانيًا
  1. سجّل في Oracle Cloud Free Tier واختر منطقة جدة (Jeddah) أو الرياض (Riyadh) كمنطقة رئيسية.
  2. أنشئ خادمًا جديدًا: Compute → Instances → Create Instance، واختر صورة Ubuntu 22.04 أو 24.04 (خطة Ampere A1 المجانية ممتازة).
  3. احفظ المفتاح الخاص SSH وحمّله، ثم اتصل بالخادم: ssh -i key.key ubuntu@SERVER_IP
  4. من لوحة Oracle افتح المنافذ: VCN → Security List → Add Ingress Rules وأضف UDP 51820 وTCP 3000 من المصدر 0.0.0.0/0.
⚙️2) شغّل أمر التثبيت

الصق هذا الأمر في طرفية الخادم السعودي (SSH). سيثبّت WireGuard ولوحة التحكم ويسلّمك كلمة المرور:

curl -fsSL ... | sudo bash

أو نزّل السكربت وارفعه للخادم يدويًا:

⬇ تحميل سكربت التثبيت
curl -fsSL https://raw.githubusercontent.com/mohammedsabryalfiqi/Saudia-vpn/main/scripts/install-wireguard.sh | sudo bash
✅3) قائمة تحقق سريعة
  • الخادم في منطقة سعودية (جدة / الرياض / الدمام).
  • منفذ UDP 51820 مفتوح في الجدار الناري السحابي ولوحة المزود.
  • منفذ TCP 3000 مفتوح للوصول إلى لوحة التحكم.
  • ظهرت رسالة «تم التثبيت بنجاح» وكلمة المرور في نهاية السكربت.
  • فتحت اللوحة على http://SERVER_IP:3000 وسجلت الدخول.
  • أضفت جهازًا ومسحت QR بتطبيق WireGuard ثم فعّلته.
🧠ملاحظات مهمة
  • بعض منصات البث تحظر عناوين مراكز البيانات — جرّب منطقة أو مزودًا آخر عند الحاجة.
  • بعد التثبيت، افتح لوحة التحكم على الخادم نفسه (وليس هذه المعاينة) لإدارة أجهزتك الحقيقية.
  • غيّر كلمة المرور فورًا من الإعدادات، وفعّل HTTPS لاحقًا إن أردت.
  • النظام مفتوح المصدر بالكامل — راجع الكود على GitHub قبل التثبيت إن أحببت.
  • للراوتر: استخدم ملف الإعداد نفسه على راوتر يدعم WireGuard (مثل OpenWrt أو GL.iNet).

    هل تتصفح الآن من السعودية؟

    نفحص عنوان IP الخاص بجهازك (من متصفحك مباشرة) ونخبرك إن كان سعوديًا. شغّل WireGuard أولًا ثم اضغط الفحص للتأكد.

    🧪اختبارات إضافية
    • اختبار تسريب DNS: dnsleaktest.com
    • فحص شامل للخصوصية: whoer.net
    • تأكد أن خانة AllowedIPs في التطبيق تساوي 0.0.0.0/0, ::/0
    • أوقف أي VPN أو بروكسي آخر قبل الفحص لتجنب التعارض.
    🛠️لا يظهر IP سعودي؟
    • تأكد أن النفق مفعّل (مفتاح التشغيل أخضر في تطبيق WireGuard).
    • افتح منفذ UDP 51820 في الجدار الناري السحابي — أشهر سبب للمشاكل.
    • تأكد أن الخادم نفسه في منطقة سعودية وليس منطقة أخرى.
    • أعد استيراد ملف الإعداد بعد أي تغيير في الإعدادات.
    • أعد تشغيل الخادم أو خدمة WireGuard: sudo systemctl restart wg-quick@wg0
    🌐إعدادات الشبكة
    يُستخدم في ملفات الإعداد التي تولدها اللوحة. في الوضع المباشر يُملأ تلقائيًا.
    القيمة الافتراضية تمرر كل حركة جهازك عبر الخادم السعودي.
